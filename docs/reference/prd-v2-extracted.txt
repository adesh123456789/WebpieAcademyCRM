Product Deﬁnition & Strategic Positioning 1.1 Product statement WebPie Academic Intelligence OS is a multi-tenant, offline-first operating system for local coaching institutes and individual teachers. It preserves the physical-classroom model while digitizing the information layer around students, exams, OMR evaluation, academic diagnosis, remedial action, parents, fees, attendance, admissions and institute web presence. 1.2 Positioning We are We are not Academic intelligence system for offline coaching Generic school ERP Assessment-to-intervention platform Online course marketplace Teacher productivity and decision system Replacement for classroom teachers Hybrid cloud + optional local edge platform Cloud-only dependency White-label institute infrastructure Consumer-first national coaching brand 1.3 Core loop Measure → Diagnose → Prescribe → Learn/Practice → Re-test → Verify Mastery → Communicate → Repeat. 1.4 Commercial wedge The sales entry point is assessment intelligence, not ERP replacement. An institute can initially use only students + exam + OMR + analytics + parent reports, then progressively adopt attendance, fees, CRM, website, CBT and AI.
